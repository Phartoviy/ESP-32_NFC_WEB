# Проверки версии 1.0

Дата: 2026-10-04.

## Реальная кросс-компиляция

Arduino CLI, пакет esp32 by Espressif Systems **2.0.17**:

```
arduino-cli compile --fqbn esp32:esp32:esp32 --warnings all NFC_Web_ESP32
```

Результат: SUCCESS, код завершения 0, предупреждений компилятора в журнале нет.
- Программа: 793225 / 1310720 байт (60%).
- Глобальная память: 45424 / 327680 байт (13%).
- Сторонние Arduino-библиотеки: не используются.
- Сформирован объединённый образ для ESP32 4MB: DIO, flash 80 MHz.

## Host-тесты

g++ с -Wall -Wextra -Werror; AddressSanitizer и UndefinedBehaviorSanitizer.
LeakSanitizer отключён из-за ограничений среды исполнения.

- NDEF: точный эталонный вектор Text, все допустимые длины коротких Text/URI-записей,
  короткий/расширенный TLV, недостаточная ёмкость, пустой ввод, UTF-8: PASS.
- HEX: длина, недопустимые символы, пробелы/двоеточия: PASS.
- Classic 1K/4K: блок 0, все sector trailer, диапазоны блоков: PASS.
- PN532 через FakeWire: формирование кадров и checksum, инициализация, выбор NTAG213,
  выбор Classic, UID, чтение, запись страницы, аутентификация, ошибка статуса и повреждённый checksum: PASS.
- JavaScript: node --check: PASS.
- HTML/JavaScript: уникальность id и наличие используемых DOM-элементов: PASS.

## Не проверено

Нет физического ESP32/PN532/меток: I2C на реальной плате, дальность и устойчивость RF,
реальная запись/чтение NTAG/Classic, запуск Wi-Fi, браузер на устройстве и отключение питания
во время записи не тестировались. Эмулятор Wire проверяет обработку заданных кадров, а не
электрические свойства шины и поведение всех ревизий PN532. Другие версии Arduino core
и платы C3/S3 не компилировались. Это первая версия для аппаратной проверки, не аппаратно
сертифицированное устройство.
